# 모르스 부호 해석기 (Morse Code Interpreter)

휴대폰에서 바로 쓰는 모르스 부호 **생성기 + 해석기**입니다.
화면 위쪽에서 글자를 입력하고, 아래쪽 **해독 트리**에서 소리가 한 칸씩 해석되는 과정을 눈으로 따라갑니다.

설치할 것이 없습니다. `index.html` 하나만 열면 동작하고, 인터넷이 끊겨도 그대로 씁니다.

---

## 화면 구성

### 1. 위 — 입력
- **언어 선택**: `A 영문` / `가 한글`. 고르면 부호표와 아래 해독 트리가 그 언어로 바뀝니다.
- **텍스트 칸**: 글자를 입력하면 아래 모르스 칸이 즉시 채워집니다. 숫자와 문장부호는 두 언어 모두 씁니다.
- **모르스 칸**: 반대로 `· −` 또는 `. -` 를 입력하면 위 텍스트 칸이 채워집니다. 낱말 사이는 `/` 입니다.
  한글은 자모가 저절로 한 글자로 모아집니다 (`ㅎ ㅐ` → `해`).
- **재생**: 실제 전신음(사인파)으로 송신하며, 동시에 아래 트리가 그 소리를 따라 내려갑니다.
- **속도**: 5–30 WPM. 1단위(1u) 길이는 `1200 ÷ WPM` ms 입니다 (PARIS 기준).
- **신호음**: 200–1200 Hz. **음량**과 함께 언제든 조절할 수 있고, `🔔 시험음`으로 지금 설정을 들어 볼 수 있습니다.
- **소리 / 진동 / 섬광**: 진동과 섬광은 소리를 낼 수 없는 상황이나 야간 신호 확인에 씁니다.

### 2. 아래 — 해독 트리
가운데 위 안테나에서 출발해 부호 하나마다 한 칸씩 이동합니다.

| 위치 | 가로 이동 | 아래로 떨어짐 |
|---|---|---|
| 왼쪽 절반 (T 쪽) | 대시 ( − ) | 도트 ( · ) |
| 오른쪽 절반 (E 쪽) | 도트 ( · ) | 대시 ( − ) |

- 선 가운데의 **작은 점 / 막대**가 그 갈래의 부호를 알려 줍니다.
- 현재 위치는 초록색으로 빛나고, 글자가 확정되면 노란색으로 한 번 번쩍입니다.
- 트리의 글자를 누르면 위 입력창에 그 글자가 추가됩니다.
- 알파벳 26자(한글은 자모 26자)는 4단계 안에 모두 들어갑니다. 숫자와 문장부호는 5단계 이하라
  트리 밖으로 나가며, 이때는 기호 칸에 부호가 그대로 쌓이고 글자만 확정되어 표시됩니다.
- 작은 빈 동그라미는 글자가 없이 **지나가기만 하는 자리**입니다 (한글 트리의 `−−·`).

### 3. 신호 입력 방식 세 가지
| 모드 | 설명 |
|---|---|
| **▶ 재생 해독** | 입력한 내용을 소리로 내보내면서 그 소리를 그대로 해독해 보여 줍니다. 교육·시범용. |
| **⌨ 전건(탭)** | 큰 버튼을 직접 두드려 송신합니다. 짧게 누르면 도트, 길게 누르면 대시. PC에서는 스페이스바. |
| **🎙 마이크** | 주변에서 들리는 삐 소리를 실제로 받아 해독합니다. (마이크 권한 필요) |

**자동 속도**를 켜 두면 보내는 사람의 손 속도에 맞춰 1u를 스스로 추정합니다.
끄면 속도 슬라이더 값을 기준으로 판정합니다.

#### 마이크 모드 다루기
- **감도(dB)**: 신호로 볼 기준입니다. 막대가 노란 눈금을 넘으면 신호로 봅니다.
  소리가 잡히지 않으면 낮추고, 주변 소음에 자꾸 반응하면 높이세요 (기본 9 dB).
- **주파수 자동**: 250–1500 Hz에서 가장 센 소리를 스스로 찾습니다.
  끄면 위 **신호음** 값 ±80 Hz만 골라 들어 시끄러운 곳에서 유리합니다.
- 표시줄에 `수신 ● 24 dB · 712 Hz · 1u ≈ 100 ms` 처럼 지금 무엇을 얼마나 잘 듣고 있는지 나옵니다.
- 신호가 2초를 넘도록 끊기지 않으면 잡음에 붙은 것으로 보고 스스로 풀고 다시 기준을 잽니다.
- 마이크는 브라우저 정책상 **https 주소**에서만 열립니다.

## 길이 규칙 (국제 모르스 부호)

| 항목 | 길이 |
|---|---|
| 도트 ( · ) | 1단위 |
| 대시 ( − ) | 3단위 |
| 한 글자 안 부호 사이 | 1단위 |
| 글자와 글자 사이 | 3단위 |
| 낱말과 낱말 사이 | 7단위 |

실시간 해독(전건·마이크)에서는 사람의 손이 정확할 수 없으므로,
부호는 **2u**를 기준으로 도트/대시를, 쉼은 **2.2u**에서 글자, **5u**에서 낱말을 끊습니다.
(각 구간의 중간값이라 조금 빠르거나 느려도 잘 읽힙니다.)

1u는 켜진 길이와 쉰 길이를 **함께** 재서 잡습니다. 소리를 재는 창 때문에 켜짐은 실제보다 길게,
쉼은 짧게 잡히는데, 둘을 평균 내면 그 치우침이 서로 지워지기 때문입니다.
첫 글자는 상대 속도를 모른 채 판정하므로, 글자를 확정하기 직전에 그동안 알아낸 속도로 다시 읽어 바로잡습니다.

## 한글 모스 부호

자모 하나에 부호 하나를 씁니다 (국제 부호의 자리를 그대로 빌려 씁니다).

| | | | | | | |
|---|---|---|---|---|---|---|
|ㄱ `·−··`|ㄴ `··−·`|ㄷ `−···`|ㄹ `···−`|ㅁ `−−`|ㅂ `·−−`|ㅅ `−−−`|
|ㅇ `−·−`|ㅈ `·−−·`|ㅊ `−·−·`|ㅋ `−··−`|ㅌ `−−·−`|ㅍ `−−−·`|ㅎ `·−−−`|
|ㅏ `·`|ㅑ `··`|ㅓ `−`|ㅕ `···`|ㅗ `·−`|ㅛ `−·`|ㅜ `····`|
|ㅠ `·−·`|ㅡ `−··`|ㅣ `··−`|ㅐ `−−··`|ㅔ `−·−−`| | |

ㄲ ㄸ ㅃ ㅆ ㅉ 과 겹받침·겹모음은 따로 부호가 없어 **낱자 둘로 나누어** 보냅니다
(ㄲ = ㄱ ㄱ, ㅘ = ㅗ ㅏ, ㄳ = ㄱ ㅅ). 받은 쪽에서는 자모를 한 글자로 도로 모읍니다.

영문과 한글은 같은 부호를 나누어 쓰므로(`−·−` 는 K 이자 ㅇ), **보내는 쪽과 받는 쪽이
같은 언어로 맞춰 두어야** 합니다.

## 휴대폰 홈 화면에 앱처럼 두기

1. 이 저장소를 GitHub Pages로 켭니다 — Settings → Pages → Branch를 이 브랜치로 지정.
2. 휴대폰 브라우저로 그 주소를 엽니다.
3. **Android Chrome**: 메뉴 → *홈 화면에 추가* / **iPhone Safari**: 공유 → *홈 화면에 추가*.

한 번 열어 두면 `sw.js`가 화면을 저장해 두어 **비행기 모드나 통신 두절 상황에서도** 그대로 동작합니다.
(마이크 기능은 브라우저 정책상 https 또는 localhost에서만 켜집니다. 파일을 직접 열었을 때는
재생·전건 모드만 동작합니다.)

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 전체 (HTML · CSS · JS 한 파일, 외부 라이브러리 없음) |
| `manifest.json` | 홈 화면 추가용 설정 |
| `icon.svg` | 앱 아이콘 |
| `sw.js` | 오프라인 캐시 |

트리 배치는 코드 안에서 계산합니다. 왼쪽 절반은 대시가 가로, 오른쪽 절반은 도트가 가로로 뻗고,
남는 가지는 아래로 떨어뜨린 뒤 짧은 가지부터 위 행에 채워 압축합니다
(영문 8열 × 7행, 한글 8열 × 8행). 언어를 바꾸면 같은 규칙으로 다시 계산해 그립니다.
